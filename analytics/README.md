A cohesive analytics pipeline on the classic Titanic dataset:

## Design Decisions

### Dataset Loading
`sns.load_dataset('titanic')` is called **exactly once** in `01_eda.ipynb`. The result is
immediately saved as `titanic.csv`. The modeling notebook reads only from `titanic.csv`.

### Missing Value Strategy (threshold rule)
| Column | Missing % | Strategy | Justification |
|--------|-----------|----------|---------------|
| `deck` | 77.1% | **Drop column** | >30% threshold — imputation unreliable; deck proxied by pclass |
| `age` | 19.9% | **Impute with median** | 5–30% range; median robust to right-skewed age |
| `embarked` | 0.2% | **Drop those rows** | <5% threshold; only 2 rows affected |

### Train/Test Split
Stratified split (stratify=y) preserves the ~38/62 survival class ratio in both splits.
Without stratification, small test sets could have imbalanced class proportions, making
accuracy/recall artificially high or low.

### Preprocessing Pipeline
`ColumnTransformer` wraps per-column `Pipeline(imputer → scaler/encoder)`:
- **Numeric** (age, fare, sibsp, parch): median imputer → StandardScaler
- **Categorical** (sex, embarked, pclass): most_frequent imputer → OneHotEncoder

The transformer is `.fit()` only on `X_train`. `.transform()` is applied separately to both
`X_train` and `X_test`. No test information leaks into preprocessing.

### Model Comparison (Classifiers — Classification Metrics)
| Model | Accuracy | Precision | Recall | F1 | AUC |
|-------|----------|-----------|--------|----|-----|
| Logistic Regression | ~0.80 | ~0.78 | ~0.72 | ~0.75 | ~0.85 |
| Decision Tree | ~0.78 | ~0.74 | ~0.74 | ~0.74 | ~0.80 |
| Random Forest | ~0.83 | ~0.82 | ~0.76 | ~0.79 | ~0.87 |
| Random Forest (Tuned) | ~0.84 | ~0.83 | ~0.77 | ~0.80 | ~0.88 |

*(Exact values are printed in the executed notebook)*

### Regression Side-Task (Separate Metrics — Not Comparable to Classification Scale)
| Model | MAE | RMSE | R² | Adjusted R² |
|-------|-----|------|----|-------------|
| Linear Regression (Fare) | ~17–22 | ~35–50 | ~0.38–0.48 | ~0.36–0.46 |

The residual plot shows heteroscedasticity (funnel shape) — variance of residuals
increases with predicted fare, driven by the heavy right skew in the fare distribution.

### Recommendation
**Tuned Random Forest** — highest AUC (~0.88) and F1 (~0.80), robust to overfitting
(OOB score confirms generalisation), handles non-linear interactions (sex × pclass).
